# 🌿 Chimera Grove / Химерний Гай

**Genre:** 2D Pixel Art Alchemy Farming / Life Sim  
**Engine:** Godot 4.x  
**Status:** 🟢 Early Development  

---

##  English

### 📖 About the game
You are an exiled alchemist trying to restore a magical garden in the heart of the Old Forest. Grow magical plants, befriend forest spirits, and explore the mysterious Root Network.

###  Core mechanics
- **Alchemy farming** — grow magical ingredients instead of regular crops.
- **Forest spirits** — care for chimera creatures instead of cows and chickens.
- **The Root Network** — explore a procedurally generated underground mycelium maze.
- **Potion crafting** — brew elixirs and upgrade your alchemical tools.

### 🛠 Project structure
- `/assets` — Pixel art, sounds, fonts.
- `/scenes` — Godot scenes (player, levels, UI).
- `/scripts` — GDScript code.
- `/docs` — Design documents and notes.

### 🚀 How to run
1. Install [Godot 4.x](https://godotengine.org/).
2. Clone this repository.
3. Open `project.godot` in Godot Engine.
